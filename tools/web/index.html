확정 텍스트(흰색)는 클릭 후 키보드로 직접 수정할 수 있습니다. 편집 중에는 서버 확정문만 덮어쓰지 않고, 회색 partial은 계속 갱신됩니다.
ESP32가 /upload 로 1초 단위 PCM 청크를 내면 자동으로 인식됩니다.
말하기는 TTS(Supertonic, 실패 시 say)로 음성을 만들어 맥 스피커에서 재생합니다. ESP32는 /speaker/pull로 상태·감정만 받아 표정을 맞춥니다.
물어보기는 기본 Ollama qwen2.5:14b, 전환은 LLM_BACKEND=openai + OPENAI_API_KEY. 발화 종료 시 자동 답변(ROBOT_AUTO_REPLY=1).
